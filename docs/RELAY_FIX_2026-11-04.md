# Relay fix 2026-11-04 ("Trying relay… 32s" CA↔RU)

## Incident
2026-11-04 15:10 UTC: Android (Calgary, 5G) matched an Android in Yekaterinburg.
Video never connected; UI stuck on "Trying relay…" + Retry; banner `offer watchdog … ice=24599`.

## Root causes
1. **Zombie partner (direct cause).** RU client 15a72aa0 stopped sending frames at 15:06:58
   (JS frozen: app backgrounded / screen off) while its WebSocket stayed open until 15:23:49
   (OkHttp answers protocol pings natively). The hub still matched it at 15:10:44 as offerer;
   it never sent offer/ICE/av_path. The CA side waited, re-hunted and was matched to the same zombie again.
2. **TURNS dead since 2026-10-13 ~18:57 UTC.** Oct 13 deploy ran `setup-turn.sh`, which rewrote
   `/etc/turnserver.conf` from `coturn.conf` with the TLS lines commented ("enable after certs exist").
   Last TLS session on 5349: 2026-10-13 18:51 UTC. `turns:…:443` (haproxy → 5349) and `turns:…:5349` failed.
   The cert-sync `/opt/ruletka/bin/setup-turns-tls.sh` had also been wiped by `push.sh` (`rsync --delete bin/`),
   so `ruletka-turns-certs.service` failed with 203/EXEC. RU mobile (UDP / plain TURN often DPI-blocked) had no relay.

## Fix
- Bridge (`bridge/src/simple.rs`): per-client `last_rx` / `last_active_rx`.
  - Waiter with no frame for 30s (app sends JSON ping every 10s) is not matched; it is matched again as soon as it sends anything.
  - 1v1 stranger match: if the partner sent no offer/ICE/any non-ping frame for 20s after the match and
    stopped pinging (or 45s even while pinging), the match is dissolved; the live side gets the usual
    `partner disconnected — searching again` (already in app/web i18n) and is re-matched immediately.
  - Tests: `stale_waiter_not_matched_until_it_wakes`, `zombie_partner_dissolved_live_side_hunts_again`,
    `slow_but_alive_partner_not_dissolved`.
- coturn: `coturn.conf` template now has `tls-listening-port=5349` + cert/pkey ON.
- `scripts/deploy/setup-turns-tls.sh` → installed as `/usr/local/sbin/ruletka-turns-tls.sh` (outside `bin/`):
  syncs Caddy's ruletka.vip cert, re-adds TLS lines if missing, restarts coturn / SIGUSR2 on cert change.
  Unit + timer in `scripts/deploy/ruletka-turns-certs.{service,timer}`; `setup-turn.sh` installs them; `push.sh` ships them.
