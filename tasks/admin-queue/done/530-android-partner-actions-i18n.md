# Android partner-actions i18n

## Goal
Add overlay + pack keys for tap-a-face partner actions on Android.

## OWN
- `mobile/src/i18n/overlay/*.json`
- `mobile/src/i18n/packs/en.json` (and other packs only if you already have the same key path)

## Must not
- live.tsx, LiveStageVideo, MediaSession, deploy, APK, ICE

## Keys
- `mobile.live.partnerActions` = Partner actions
- `mobile.live.actionsFor` = Actions · {{name}}
- `mobile.live.tapPartnerHint` = Tap a face for their actions

English required; other langs copy English if you cannot translate.
