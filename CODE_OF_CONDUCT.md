# Code of Conduct

## Our pledge

We want a welcoming community around open peer-to-peer video chat software. We pledge to make participation a harassment-free experience for everyone, regardless of age, body, disability, ethnicity, gender identity, experience level, nationality, religion, or sexual identity.

This project is **18+** by product design. Discussions about safety tools (block, report, blur) are first-class, not optional.

## Our standards

**Positive examples**

- Respectful issue and PR discussion
- Focusing on what is best for users and operators
- Graceful disagreement and documented decisions
- Assuming good intent while verifying technical claims

**Unacceptable**

- Harassment, hate speech, sexualized attention in project spaces
- Doxxing or publishing others’ private information
- Trolling or sustained disruption
- Publishing exploit details for unfixed issues (use `SECURITY.md`)
- Using community channels to target people in live chat

## Scope

This Code applies in GitHub issues/PRs, discussions, and any official project chat. It does not replace local laws or the product’s in-app Rules / EULA for end users of a hub.

## Enforcement

Report conduct concerns to **support@ruletka.me** (or GitHub maintainers for repo-only issues). Maintainers may warn, moderate, or ban contributors who violate this Code.
