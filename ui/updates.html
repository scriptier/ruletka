Server hardening & ops

  • Firewall — UFW deny-by-default; only SSH, HTTPS, and TURN open.
  • SSH — keys only, no passwords; root key-only; fail2ban on login storms.
  • Deploy user — non-root deploy account for day-to-day ops.
  • Backups — daily data backups + operator pull script for off-box copies.
  • Auto security reboot — unattended upgrades can reboot off-peak when a kernel needs it.
2026-08-04

Stars reputation — social score v2

  • Dual system — Balance (spend on gifts) vs Trust (peer ★ gifts only). Hour bonuses raise balance, not trust.
  • Wealth chrome — high spendable ★ (e.g. 250+) looks legendary even if trust is still low.
  • Status ladder — New / Known / Trusted / Senior language (not “reporter ×N ban power”).
  • Social map — Power/Status tab: balance, trust, gifters, decay countdown, soft match-rank.
  • Gifter strip — progress dots to 5 (Trusted floor) and 12 (Senior floor).
  • Gift unlock bar — mid-chat ★ progress (50% / 80% / ready) next to the timer.
  • Thanks — post-chat Thanks/vouch (no trust mint) alongside gift / skip.
  • Mutual bonds — friends list ★↔ / 🙏↔ chips; bonded friends sorted first.
  • Partner praise — “praised by N” on the partner tile; gift-back reciprocity nudge.
  • Stuck CTA — clear next step when wealth is high but trust/gifters block tier.

2026 · Stars phases A–D

Stars foundation

  • Post-chat gifts — after long chats, gift ★ once per person (15 min; first partners 5 min early ramp).
  • Hour reward — both get +1★ balance after a full hour together.
  • Spend gifts — hearts, bars, flowers, balloons, confetti, fireworks, Please stay.
  • Trust vs balance — ledger split; gifter floors; soft idle decay; ban clawback.
  • Soft match rank — Trusted/Senior lightly preferred when the lobby is busy (never blocks matches).
  • Never for sale — stars stay hub-side; profile export never includes balances.
2026 · Core product

Core chat roulette

  • P2P WebRTC — video browser-to-browser; hub for match + signaling only.
  • No classic account — browser identity + export/import profile (QR / share / file).
  • Friends — codes, requests, DMs, call when online; party / find-third paths.
  • Safety tools — Next, Block, Report, blur-first strangers, optional on-device NSFW skip.
  • Hide my IP — force TURN relay-only ICE when you want extra path privacy.
  • Languages — 10 UI languages at full parity.
  • Open source — self-host docs, Docker, desktop helper ZIPs (Windows / macOS / Linux).
  • Speed — lean first paint, SW update banner, live stack no-stale deploys.
