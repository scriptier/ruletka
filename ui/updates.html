2v2 hunt · TURNS 443 · Stop idle

  • Find 3rd — a pair hunting a 3rd can match one person (2v1) or another pair that also accepted Find 3rd (2v2). Fourth from a live 3-way is still Call / Invite 4th. Never 5 people.
