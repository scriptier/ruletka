How we’re different

Most chat roulettes send your video through big company servers and push ads or accounts. ruletka.vip is built so video stays between two browsers (peer-to-peer), with no signup required. You get friends, block, report, and on-device safety tools — and you can even help the network grow without giving anyone else control of this site.

Open source & multi-hub

This software is open source (LGPL-2.1). Anyone can run their own hub. This site is a public seed — not the only network. If a hub goes down, the live app can try other hubs from a public directory. Helpers run a full chat node you can share.

Advanced: run a full hub (operators)

For people who already have a VPS and HTTPS. Federation is by invite only so random nodes can’t take over the site. 

# Full hub (HTTPS public URL required)
export ROULETTE_INSTANCE_ID=my-hub
export ROULETTE_FEDERATION_TOKEN='agree-with-operators'
export ROULETTE_PUBLIC_BASE=https://your-hub.example.com
export ROULETTE_FEDERATION_PEERS=https://ruletka.vip
./scripts/run-bridge.sh

Contact operators with your hub URL to join the live mesh. We do not auto-trust unknown hubs.
