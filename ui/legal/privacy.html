Privacy policy

Last updated: 2026-07-31

ruletka.vip is a peer-to-peer video chat service. This page describes what we process.

Video and audio

Call media (camera/microphone) is exchanged directly between browsers (WebRTC, encrypted with DTLS/SRTP) when the network allows a direct path. We do not operate a media server that stores or rebroadcasts your video/audio streams.

If a direct connection fails, media may be relayed through a TURN server (still encrypted for the media path). Prefer a direct path when the UI shows “Direct P2P”.

Your partner can always screenshot or record what they see. Use Block and Report if needed.

Signaling and matchmaking

To match strangers and connect calls, our bridge may process temporary connection data (WebSocket session ids, display names you choose, room codes, friend codes, and WebRTC signaling messages). This is needed for the service to work. We minimize long-term retention of signaling payloads.

Reports and safety

If you report a user, we store the report (reporter id, target id, reason, time) to fight abuse. Multiple independent reports may temporarily restrict matchmaking for the reported identity on this hub. Optional on-device AI may send an assisted report signal without uploading video to us. See Safety.

Local device data

Your browser may store preferences (language, devices, friend history, identity) in localStorage and a device crypto key in IndexedDB (when available). You can export a profile file (Settings → About → Export) to move the same identity to another browser or device; friends lists are stored on the match hub under that identity id. You can clear local data from Settings → Clear local data.

Friends and blocks

Friend lists and blocks for this hub are stored on the server instance you connected to, so features like call-when-online can work.

Analytics

If the operators enable analytics, public measurement ids may be loaded via /config.json (for example Yandex Metrica or Google Analytics). No analytics run unless those ids are configured.
